# discovery/

Artefatos de descoberta em estágio inicial (antes do PRD formal), organizados por item de trabalho em `work-items/<CHAVE_DO_ITEM>/`.

Arquivos obrigatórios por item de trabalho:
- `discovery-brief.md`
- `mvp-scope.md`

Arquivos opcionais:
- `competitive-landscape.md`
- `resourcing-plan.md`
- `job-description-<papel>.md`
- `onboarding-and-access.md`

Modelos prontos para copiar estão em [`_modelos/`](_modelos/).

Veja as regras completas em [`.bob/rules-discovery-vision/01-descoberta-visao-recursos.md`](../.bob/rules-discovery-vision/01-descoberta-visao-recursos.md).
