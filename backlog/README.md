# backlog/

Backlogs por item de trabalho. Cada arquivo é nomeado `<CHAVE_DO_ITEM>.md` e contém as histórias/epics daquele item de trabalho.

O índice geral fica em [`../backlog.md`](../backlog.md).

Veja o modelo completo de história e as regras de organização de epics em [`.bob/rules-product-owner/01-po.md`](../.bob/rules-product-owner/01-po.md).

## Modelo rápido de história (copie e preencha)

### História: <Título orientado a ação>
- Como <persona>
- Eu quero <capacidade>
- Para que <benefício/resultado>
- Prioridade: <P0/P1/P2>
- Story Points (Dias): <1|2|3|4|5|6>
- Dependências: <nenhuma | lista>
- Critérios de Aceite (Gherkin):
  - Cenário 1: <nome>
    - Dado ...
    - Quando ...
    - Então ...
- Não-Objetivos:
  - ...
